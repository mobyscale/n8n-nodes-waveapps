# Reference Data

Lists of values that Wave uses in other records. Use them to look up codes, or to check values before you create records.

## Operations

| Operation | Description | Fields |
|---|---|---|
| Get Account Subtypes | Get the account subtypes of the chart of accounts, with their account type | |
| Get Account Types | Get the account types (asset, liability, equity, income, expense) and their normal balance | |
| Get Countries | Get all countries, with their currency and provinces | |
| Get Country | Get one country | **Country** |
| Get Currencies | Get all currencies | |
| Get Currency | Get one currency | **Currency** |
| Get Province | Get one province or state by its ISO 3166-2 code, for example `CA-ON` | **Province** |
